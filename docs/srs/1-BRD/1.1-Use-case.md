# 1.1 Use case – StructPaper

Tài liệu liệt kê **toàn bộ use case** của hệ thống dưới dạng bảng. Mỗi use case có mã `UC-<module>-nn` dùng xuyên suốt các sơ đồ (2.1–2.3).

## 0. Actor

| Actor | Mô tả | Cách xác định trong hệ thống |
|---|---|---|
| **Guest** | Người không có tài khoản, mở bài bằng đường dẫn | Không có token; chỉ `GET /manuscripts/:id`, `GET /manuscripts/:id/preview` khi `generalAccess = VIEWER` |
| **Author** | Người soạn bài (chủ sở hữu / đồng tác giả) | Vai trò hệ thống `Author` (được `create Manuscript`) + thành viên bài `OWNER`/`COAUTHOR` |
| **Viewer / Reviewer** | Người chỉ xem (phản biện, khách đã đăng nhập) | `manuscript_members.role` = `REVIEWER`/`VIEWER` hoặc `general_access` |
| **Editor** | Biên tập viên | Vai trò `Editor` (đọc tạp chí, tạo bài); sửa bài người khác chỉ khi là thành viên `EDITOR` |
| **JournalManager** | Quản lý tạp chí (toàn cục hoặc theo 1 tạp chí – `scope_journal_id`) | `manage Manuscript/Journal/Role` (toàn cục hoặc `journalId`) |
| **SuperAdmin** | Quản trị toàn hệ thống | `manage all`; bất biến "luôn còn ≥ 1 SuperAdmin" |
| **System** | Tiến trình nền: worker pg-boss, scheduler dọn thùng rác, outbox dispatcher | `apps/worker`, `TrashService` timer |
| **Desktop Updater** | Cơ chế tự cập nhật của bản Tauri | `tauri-plugin-updater`, `platform-desktop` |

Quy ước cột: **Tiền ĐK** = tiền điều kiện; **Hậu ĐK** = hậu điều kiện; **Nguồn** = endpoint/mã chính.

## 1. Danh tính & phiên làm việc (AUTH)

| Mã | Use case | Actor | Mô tả | Tiền ĐK | Hậu ĐK / Kết quả | Luồng chính | Ngoại lệ | Nguồn |
|---|---|---|---|---|---|---|---|---|

| UC-AUTH-02 | Làm mới phiên | Tất cả | Đổi refresh token lấy access token mới (xoay vòng) | Còn refresh token hợp lệ | Refresh cũ bị thu hồi, cấp cặp mới | Web gọi `POST /auth/refresh` khi hết hạn/khởi động | Token hết hạn/đã thu hồi → buộc đăng nhập lại | `POST/GET /auth/refresh` |

| UC-AUTH-05 | Đặt lại mật khẩu | Người dùng | Đặt mật khẩu mới bằng token `PASSWORD_RESET` | Token hợp lệ | Mật khẩu mới; mọi refresh token cũ bị thu hồi | Nhập mật khẩu mới | Token sai/hết hạn | `POST /auth/reset-password` |
